# Herdr cockpit prototype

Throwaway visual prototype for comparing three terminal layouts.

Open `index.html` directly in a browser. Use the floating arrows, keyboard left/right arrows, or a shareable query parameter:

- `index.html?variant=A` — approximate current layout
- `index.html?variant=B` — recommended balanced cockpit
- `index.html?variant=C` — minimal layout with on-demand context

No external dependencies, persistence, or real mutations are involved.
