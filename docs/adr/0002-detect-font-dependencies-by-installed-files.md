# Detect font Dependencies by installed-file presence

Dependency presence was probed only as an executable on the search path: each Dependency's `Probe` string is resolved with a path lookup, defaulting to its command or name. A font has no executable on the path, so a declared Font Dependency such as `CaskaydiaCove Nerd Font` always reported missing and never converged. We will extend the `Dependency` model with an optional font-match field; when it is present, the Dotfiles CLI detects presence by scanning the workstation font directories for matching installed files instead of doing a path lookup. The scan is recursive, matches case-insensitively against the file name, treats a missing directory or permission error as "not found here" rather than an error, and never aborts `dots deps check`.

**Considered Options**: `fc-list` (fontconfig) is the obvious cross-platform probe but is not installed by default on macOS, so detecting a font would first require installing fontconfig — circular. `system_profiler SPFontsDataType` is macOS-native but slow enough to penalise `dots deps check` and has no Linux equivalent. Reading the Homebrew cask receipt (`brew list --cask <token>`) is simple on macOS but couples detection to a single installer and does not work on Linux. Scanning the font directories on disk needs no extra tooling, is installer-agnostic (brew, package manager, or a manual copy all satisfy it), and stays a bounded file scan that the CLI owns rather than arbitrary shell execution, which the manifest contract excludes (see ADR 0001).

**Consequences**: `Dependency` now carries two detection modes selected by the presence of the font-match field, which is a small overload to keep documented. Detecting a font is not the same as provisioning it: fixing the Homebrew `--cask` install path and any Linux font provisioning remain separate work, and Linux auto-provisioning would reopen the "no arbitrary shell execution" boundary. The existing declared font is migrated from the patched fork `font-caskaydia-cove-nerd-font` to Microsoft's official `font-cascadia-code-nf`, whose NF variant ships the full Nerd Font glyph set, with `font_match: "CascadiaCodeNF*"`.
